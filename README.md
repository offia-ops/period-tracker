🌸 月經週期追蹤小幫手 (Menstrual Cycle Tracker)

一個輕量、溫馨且強大的女性週期健康追蹤 Web 應用程式。整合了智能日曆推算、歷年紀錄管理與個人化參數設定。

🌟 主要功能

1. 📅 智能日曆與週期預測

多重狀態標記：以直觀顏色標示實際月經期、預測月經期、排卵日（高度易孕）、易孕期（危險期）與安全期。

動態推算算法：根據個人設定與最近一次的月經紀錄，精確預測未來數個週期的時間。

2. 📝 歷年紀錄管理

紀錄管理：支援完整新增、瀏覽與刪除過去的行經紀錄。

即時編輯修訂：支援直接在清單中修改（校正）過往的起訖日期，並自動防呆限制 4 位數合理西元年份。

3. ⚙️ 個人化設定

週期彈性調整：支援以流暢滑桿自訂平均月經週期（21 - 45 天）。

行經期彈性調整：支援自訂平均行經天數（3 - 10 天），修改後月曆預測將即時更新。
